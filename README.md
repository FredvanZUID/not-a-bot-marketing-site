# Not-a-bot.ai Marketing Site

Conversion-optimized sales website for [not-a-bot.ai](https://www.not-a-bot.ai).

## Stack
- Static HTML/CSS/JS
- Supabase (lead capture)
- Netlify (hosting)

## Languages
EN / NL / FR

## Structure
```
├── index.html              # Homepage (EN)
├── nl/index.html           # Homepage (NL)  
├── fr/index.html           # Homepage (FR)
├── pricing.html
├── use-cases/
│   └── vacation-rentals.html
├── roi-calculator.html     # Lead magnet
├── demo.html               # SQL: demo request
├── assets/
│   ├── css/main.css
│   ├── js/main.js
│   ├── js/supabase-forms.js
│   └── js/roi-calculator.js
├── netlify.toml
└── docs/                   # Marketing plan, personas, nurture flows
```
